# 🔗 Tabela Hash com Encadeamento Separado

> Implementação acadêmica de uma tabela hash genérica em Java, usando listas encadeadas para resolver colisões.

## ✨ Funcionalidades

- Inserção de pares de chave e valor
- Busca e verificação de chaves
- Alteração e remoção de registros
- Redimensionamento por fator de carga
- Importação opcional de dados em CSV
- Visualização dos elementos por posição da tabela

## 🧠 Conceitos praticados

- Tabelas hash
- Encadeamento separado
- Listas encadeadas
- Generics em Java
- Fator de carga e redimensionamento

## ▶️ Como executar

```bash
javac App.java CustomHashMap.java
java App
```

Ao iniciar, informe um CSV no formato `chave,valor` ou pressione Enter para usar a tabela vazia.

## 📁 Arquivos principais

- `App.java`: menu da aplicação
- `CustomHashMap.java`: implementação da estrutura
